# API Reference

Base URL (local dev): `http://localhost:8000`

## Analysis

| Method | Path | Description |
|---|---|---|
| POST | `/api/analyze/upload` | Upload audio (multipart form) + optional caller claims; runs the full pipeline synchronously and returns the result. |
| GET | `/api/analysis/{id}` | Fetch a persisted analysis session. |
| GET | `/api/analysis/{id}/segments` | Per-segment predictions and transcript. |
| GET | `/api/analysis/{id}/explanation` | Evidence items for a session. |

## Verification

| Method | Path | Description |
|---|---|---|
| POST | `/api/verify/organization` | `{claimed_organization}` → verification state. |
| POST | `/api/verify/branch` | `{claimed_organization, claimed_branch, claimed_city}` → verification state. |
| POST | `/api/verify/caller` | Full caller verification (org + branch + caller ID). |
| POST | `/api/verify/conversation` | `{transcript_segments}` → OTP + conversation-pattern analysis. |

## Research

| Method | Path | Description |
|---|---|---|
| GET | `/api/models` | Status + model card for every detector. |
| GET | `/api/models/{key}/card` | Single model card. |
| GET | `/api/models/cards` | All model cards. |
| GET | `/api/experiments` | Experiment history. |
| POST | `/api/experiments/run` | Run/record an ASVspoof-style evaluation (see `docs/research/asvspoof.md`). |

## Reports

| Method | Path | Description |
|---|---|---|
| GET | `/api/reports/{id}` | Download the PDF report for a completed session. |

## Live

| Protocol | Path | Description |
|---|---|---|
| WebSocket | `/api/live/stream` | Browser-mic PCM16 chunks in, per-window fusion+risk results out. |

## Demo

| Method | Path | Description |
|---|---|---|
| GET | `/api/demo/scenarios` | List the 4 predefined demo scenarios. |
| GET | `/api/demo/scenarios/{key}` | Full precomputed, clearly-labeled demo scenario payload. |

## Health

| Method | Path | Description |
|---|---|---|
| GET | `/health` | Liveness/readiness check. |

Full interactive docs are also available at `/docs` (Swagger UI, auto-generated by FastAPI) once the backend is running.
